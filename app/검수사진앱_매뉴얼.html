검수사진 앱 (GRfiti) 사용 매뉴얼

구매건을 고르고 사진을 찍으면 사내 파일서버의 부서 폴더에 자동으로 저장되는 앱입니다.
사진을 메신저로 따로 보내거나 폴더에 옮길 필요가 없습니다.

01 개요

1-1. 사용 순서

로그인→ 구매건 선택→ 검수자 이름 입력→ 촬영→ 저장→ 파일서버 자동 저장

1-2. 구매건 목록

앱에 보이는 구매건은 구매요청 데이터 중 발주가 끝나고 아직 입고되지 않은 건입니다. 로그인한 부서의 건만 보입니다. 구매번호를 직접 입력하거나 스캔할 필요 없이 목록에서 고르면 됩니다.

1-3. 지원 기기

구분설치 방법
안드로이드설치 파일(APK)을 받아 직접 설치 — 2장
아이폰전략구매팀이 기기에 직접 설치 — 3장

02 설치 — 안드로이드

이 앱은 Play 스토어가 아니라 설치 파일(APK)로 배포합니다. 안드로이드는 스토어 밖에서 받은 앱을 기본으로 막아 두므로, 설치할 때 아래 보안 설정을 한 번 허용해야 합니다.

2-1. 설치 파일 받기

  1. 전략구매팀에서 받은 GRfiti.apk 파일을 휴대폰에 내려받습니다.
  2. 내 파일 → 다운로드 폴더(또는 받은 메신저의 파일 목록)에서 파일을 누릅니다.

2-2. 출처를 알 수 없는 앱 허용

파일을 누르면 「보안을 위해 이 출처의 알 수 없는 앱을 설치할 수 없습니다」 안내가 나옵니다.

  1. 안내창의 설정을 누릅니다.
  2. 이 출처 허용(또는 「출처를 알 수 없는 앱 설치」)을 켭니다.
  3. 뒤로 돌아와 설치를 누릅니다.

안내창이 나오지 않으면 직접 켭니다.

기종경로
삼성 갤럭시설정 → 애플리케이션 → 우측 상단 ⋮ → 특별한 접근 → 알 수 없는 앱 설치 → 파일을 연 앱(내 파일 등) → 허용
그 밖의 기종설정 → 앱 → 특별한 앱 액세스 → 알 수 없는 앱 설치 → 파일을 연 앱 → 허용

2-3. 자동 차단 해제 (삼성 갤럭시)

최근 갤럭시(One UI 6 이상)는 자동 차단이 켜져 있으면 2-2를 허용해도 설치가 막힙니다.

  1. 설정 → 보안 및 개인정보 보호 → 자동 차단
  2. 스위치를 끔으로 바꿉니다.
  3. 설치가 끝나면 다시 켜도 앱 사용에는 지장이 없습니다.

2-4. Play 프로텍트 경고

설치 중 「Play 프로텍트에서 앱을 차단했습니다」 또는 「안전하지 않은 앱」 안내가 나올 수 있습니다. 사내 배포 앱이라 Google 에 등록되지 않아서 나오는 안내입니다.

  1. 세부정보 더보기를 누릅니다.
  2. 무시하고 설치(또는 「그래도 설치」)를 누릅니다.
  3. 「앱 검사를 위해 보내시겠습니까」가 나오면 보내지 않음을 눌러도 됩니다.
참고 설치를 마친 뒤에는 2-2의 「이 출처 허용」을 다시 꺼 두셔도 됩니다. 앱은 그대로 사용할 수 있습니다.

03 설치 — 아이폰

아이폰은 전략구매팀이 기기를 Mac 에 연결해 설치해 드립니다. 설치 후 아래 두 가지를 기기에서 허용해야 앱이 열립니다.

3-1. 개발자 모드 켜기 (처음 한 번)

  1. 설정 → 개인정보 보호 및 보안 → 맨 아래 개발자 모드 → 켬
  2. 재시동을 누릅니다.
  3. 재시동 후 나오는 안내에서 켜기를 누르고 암호를 입력합니다.

3-2. 개발자 앱 신뢰

앱을 처음 누르면 「신뢰하지 않는 개발자」 안내가 나옵니다.

  1. 설정 → 일반 → VPN 및 기기 관리
  2. 「개발자 앱」 아래의 Apple ID 항목을 누릅니다.
  3. 신뢰를 누르고 한 번 더 신뢰를 누릅니다.
주의 아이폰 설치본은 7일마다 다시 설치해야 합니다. 앱이 열리지 않으면 전략구매팀에 요청해 주세요.

04 처음 설정

4-1. 권한 허용

처음 촬영 화면에 들어가면 권한을 묻습니다. 모두 허용해 주세요.

권한용도
카메라검수 사진 촬영
위치 (앱 사용 중에만)사진 파일에 촬영 장소 기록. 허용해야 촬영 버튼이 켜집니다
로컬 네트워크 (아이폰)사내 파일서버에 사진 저장
사진 추가 (아이폰)촬영한 사진을 앨범에도 저장
아이폰 「로컬 네트워크」를 거부하면 파일서버에 저장되지 않습니다. 거부했다면 설정 → GRfiti → 로컬 네트워크를 켜 주세요.

4-2. 파일서버 계정 입력

사진을 파일서버에 저장하려면 기기마다 한 번 계정을 넣어야 합니다.

  1. 구매건 선택 화면 왼쪽 위 설정을 누릅니다.
  2. 서버 IP 주소가 192.168.1.8 인지 확인합니다.
  3. SMB 아이디와 SMB 비밀번호에 PC 로그인 계정을 입력합니다.
  4. 연결 테스트를 눌러 「✅ 연결 성공!」을 확인합니다.
  5. 맨 아래 설정 저장을 누릅니다.
주의 「설정 저장」을 누르지 않으면 사진이 휴대폰에만 저장되고 파일서버에는 올라가지 않습니다. 연결 테스트는 사내 와이파이에 연결된 상태에서 해 주세요.

05 로그인

  1. 앱을 엽니다. 첫 화면 제목은 「FITI시험연구원 검수사진촬영앱」입니다.
  2. 부서에 안내된 아이디와 비밀번호를 입력합니다. 아이디만 입력하면 되고, 뒤에 붙는 주소는 자동으로 처리됩니다.
  3. 로그인을 누릅니다.

한 번 로그인하면 로그아웃하기 전까지 유지됩니다. 다음부터는 앱을 열면 바로 구매건 목록이 나옵니다.

06 구매건 선택

화면 위에 「○○팀 로그인중」이 보이고, 그 아래에 구매건 목록이 나옵니다.

항목내용
구매번호구매요청 번호 (예: S202609280005)
신청자구매를 요청한 직원
금액요청 금액

6-1. 선택 순서

  1. 검수할 구매건의 줄을 누릅니다.
  2. 「구매건 확인」 창에서 구매번호·신청자·금액을 확인하고 예를 누릅니다.
  3. 「사용자 이름을 입력해주세요」 창이 나옵니다. 검수자 이름을 확인합니다.
    • 신청자 이름이 미리 채워져 있습니다. 신청자가 직접 검수하면 그대로 확인을 누릅니다.
    • 다른 사람이 검수하면 지우기를 누르고 검수자 이름을 입력한 뒤 확인을 누릅니다.
  4. 촬영 화면으로 넘어갑니다.

6-2. 상단 버튼

버튼기능
설정설정 화면 (11장)
새로고침목록을 다시 불러옵니다
로그아웃로그아웃 후 로그인 화면으로 돌아갑니다
참고 사진을 저장해도 구매건은 목록에 그대로 남습니다. 같은 건을 여러 번 찍을 수 있도록 한 것입니다. 입고(검수) 처리가 끝나면 목록에서 빠지며, 새로고침을 누르면 반영됩니다. 찾는 건이 없으면 전략구매팀에 문의해 주세요.

07 촬영

  1. 왼쪽 위 상자에 고른 구매번호가 표시되는지 확인합니다.
  2. 물품이 화면에 잘 들어오게 맞춥니다.
  3. 아래쪽 흰 원(셔터)을 누릅니다.
조작기능
화면 한 번 누르기그 지점에 초점과 밝기를 맞춥니다. 옆의 ☀ 막대를 위아래로 끌면 밝기가 바뀝니다
두 손가락 벌리기·모으기확대·축소
「세로」·「가로」 버튼화면 방향 고정
오른쪽 위 톱니비율(4:3 · 16:9 · 1:1) · 화질 · 설정 · 파일 메뉴
구매번호 상자 누르기구매건 목록으로 돌아가기
참고 셔터가 흐리게 보이면 아직 위치를 확인하는 중입니다. 잠시 기다리면 켜집니다. 「위치 서비스 꺼짐」 안내가 나오면 휴대폰의 위치(GPS)를 켜 주세요.

08 확인 및 저장

촬영하면 미리보기 화면이 나옵니다.

  1. 사진이 잘 찍혔는지 확인합니다. 방향이 틀어졌으면 위쪽 회전 버튼으로 돌립니다.
  2. 다시 찍으려면 다시찍기, 괜찮으면 저장을 누릅니다.
  3. 「진위확인 코드 발급 중...」 → 「저장 중...」이 차례로 표시됩니다.
  4. 「저장 완료 (로컬+SMB)」가 뜨면 파일서버까지 저장된 것입니다. 촬영 화면으로 돌아오므로 이어서 찍을 수 있습니다.

8-1. 사진에 표시되는 내용

저장된 사진에는 아래 내용이 비스듬한 글씨로 표시됩니다. 사진 가운데는 가리지 않습니다.

구매번호 / 신청자 / 촬영 일시 / 검수자 / 진위확인코드(8자리)

진위확인코드는 이 앱으로 찍은 원본 사진인지 확인할 때 쓰는 번호입니다. 미리보기에서는 XXXXXXXX 로 보이고, 저장할 때 실제 번호가 들어갑니다.

참고 한 구매건에 여러 장이 필요하면 촬영 → 저장을 반복하면 됩니다. 다른 구매건으로 바꾸려면 왼쪽 위 구매번호 상자를 누릅니다.

10 문제 해결

증상조치
로그인이 안 됨아이디·비밀번호를 다시 확인합니다. 계속 안 되면 전략구매팀에 계정 확인을 요청합니다
「표시할 구매건이 없습니다」발주 완료·미입고 건이 없는 상태입니다. 새로고침을 눌러 봅니다
사진을 저장했는데 목록에 남아 있음정상입니다. 입고(검수) 처리가 끝나야 목록에서 빠집니다. 처리 후 새로고침을 누르면 사라집니다
「구매목록을 불러오지 못했습니다」인터넷 연결 확인 후 새로고침
셔터가 눌리지 않음위치 권한과 휴대폰 위치(GPS)가 켜져 있는지 확인합니다
「진위확인 코드 발급 실패」신호가 약한 곳입니다. 창에서 다시 시도를 누르거나, 닫기 후 신호가 좋은 곳에서 저장을 다시 누릅니다. 이때는 사진이 아직 저장되지 않은 상태입니다
「로컬 저장 완료. SMB 실패 → 대기열 추가」휴대폰에는 저장됐고 파일서버에만 못 올라간 상태입니다. 사내 와이파이에 연결한 뒤 설정 → 대기 중인 SMB 업로드 재시도를 누릅니다
「저장 완료 (로컬)」만 뜸파일서버 계정이 저장되지 않은 상태입니다. 4-2를 진행합니다
「로그인이 만료됐어요」다시 로그인합니다
「중복 파일」확인을 누르면 새 사진으로 저장됩니다
아이폰에서 앱이 열리지 않음설치 후 7일이 지났을 수 있습니다. 전략구매팀에 재설치를 요청합니다
주의 파일서버는 사내 와이파이에서만 연결됩니다. 외부에서 찍은 사진은 사내에 돌아와 재시도해 주세요.
