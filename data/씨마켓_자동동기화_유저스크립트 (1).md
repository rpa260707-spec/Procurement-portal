# 씨마켓 → 포털 자동 동기화 (유저스크립트) · v1.4

> **2026-09-28 작동 확인.** 포털 `/api/bid` 에 `savedBy:"씨마켓 자동동기화"` 로 들어옵니다.

씨마켓은 로그인 뒤에 있는 데이터라 **서버가 직접 못 읽습니다.**
이미 로그인해 있는 **내 브라우저**가 대신 읽어 포털로 보내는 구조입니다.
아이디·비밀번호는 어디에도 저장되지 않습니다.

---

## ❗ 먼저 이것부터 — 크롬 「사용자 스크립트 허용」

**크롬이 유저스크립트 실행을 기본으로 막습니다.** 이걸 안 켜면 스크립트가 설치돼 있고 켜져 있어도
**에러도, 로그도, 아무 일도 안 일어납니다.** (2026-09-23 에 이것 때문에 며칠 헤맸습니다.)

1. 주소창에 `chrome://extensions/`
2. **Tampermonkey** 카드 → **「세부정보」**
3. 아래로 내려 **「사용자 스크립트 허용」** 스위치를 **켬**
4. 씨마켓 탭에서 **F5**

Tampermonkey 팝업 맨 위에 파란 띠로 *"「사용자 스크립트 허용」 확장 설정을 활성화하세요"* 가 보이면
아직 안 켜진 것입니다. 켜지면 아이콘에 **숫자 배지 `1`** 이 뜹니다.

> 씨마켓 자체는 CSP·CORS 어느 것도 막지 않습니다 (2026-09-23 직접 확인).
> 안 되면 원인은 거의 이 설정이거나, Tampermonkey 가 없는 다른 브라우저로 씨마켓을 연 경우입니다.

## 버전 기록

| 버전 | 바뀐 것 |
|---|---|
| v1.1 | SPA 대응 — 15초마다 확인 + 주소 변경 감지 |
| v1.2 | 콘솔 로그 제거 → **오른쪽 아래 상태 점** |
| v1.3 | 유찰 사유를 **블록을 이어붙여** 파싱 (이름이 두 줄로 접히는 항목 누락 해결) |
| **v1.4** | 탭이 **백그라운드일 때만 10분마다 자동 새로고침** |

**v1.3 의 유찰 파싱이 왜 필요했나** — 「사용부서와 협의결과 조건이 맞지 않아 유찰하기로 하였습니다.」처럼
이름이 길어 화면에서 두 줄로 접히는 항목이 줄 단위 규칙에 안 걸려 **6건이 통째로 빠졌습니다.**
총 유찰은 32건인데 사유 합계가 26건이었습니다. v1.3 부터 32건으로 맞습니다.

**v1.4 의 자동 새로고침이 왜 필요했나** — 스크립트는 **화면에 그려진 글자**를 읽습니다.
탭을 새로고침하지 않으면 씨마켓 숫자가 연 시점 그대로 멈춰 있어, 스크립트는 계속
「값이 전과 같아 건너뜀」 만 합니다. 포털이 안 바뀌는 것처럼 보이는 원인이 이것이었습니다.

## 설치 / 교체

1. Tampermonkey 아이콘 → **대시보드**
2. `씨마켓 → FITI 업무포털 동기화` 클릭
3. 편집창 전체 선택(`Ctrl+A`) → 삭제 → 아래 코드 붙여넣기 → `Ctrl+S`
4. 씨마켓 탭에서 **F5**

## 코드

```javascript
// ==UserScript==
// @name         씨마켓 → FITI 업무포털 동기화
// @namespace    fiti.procurement
// @version      1.4
// @description  씨마켓 나의 거래 요약 숫자를 업무포털로 자동 전송
// @match        *://*.c-market.net/*
// @run-at       document-idle
// @grant        none
// ==/UserScript==
(function () {
  'use strict';

  var PORTAL = 'https://fiti-procurement-portal.vercel.app';
  var KEY_LS = 'fiti.bidKey';
  var SIG_LS = 'fiti.bidSig';
  var busy = false;
  var dot = null;

  function badge(color, tip) {
    try {
      if (!dot) {
        dot = document.createElement('div');
        dot.style.cssText = 'position:fixed;right:10px;bottom:10px;width:11px;height:11px;'
          + 'border-radius:50%;z-index:2147483647;box-shadow:0 0 0 2px #fff,0 2px 6px rgba(0,0,0,.3);'
          + 'transition:background .3s';
        document.body.appendChild(dot);
      }
      dot.style.background = color;
      dot.title = 'FITI 포털 동기화 · ' + tip;
    } catch (e) {}
  }

  function toast(msg, bad) {
    try {
      var d = document.createElement('div');
      d.textContent = msg;
      d.style.cssText = 'position:fixed;right:16px;bottom:30px;z-index:2147483647;padding:10px 15px;'
        + 'border-radius:10px;font-size:13px;font-weight:700;color:#fff;font-family:sans-serif;'
        + 'box-shadow:0 8px 24px rgba(0,0,0,.25);background:' + (bad ? '#dc2626' : '#16a34a');
      document.body.appendChild(d);
      setTimeout(function () { d.remove(); }, 4000);
    } catch (e) {}
  }

  function num(s) {
    var m = String(s).replace(/,/g, '').match(/-?\d+/);
    return m ? parseInt(m[0], 10) : 0;
  }

  function read() {
    var T = document.body.innerText;
    if (T.indexOf('나의 거래 요약') < 0) return null;

    function after(label) {
      var i = T.indexOf(label);
      if (i < 0) return 0;
      var m = T.slice(i + label.length, i + label.length + 40).match(/-?[\d,]+/);
      return m ? num(m[0]) : 0;
    }

    var kpi = {
      inProgress: after('진행중'),
      closed: after('전체 마감'),
      contracts: after('총 계약'),
      cardPending: after('카드 결제 대기'),
      invoices: after('계산서 및 영수증')
    };
    if (!kpi.closed && !kpi.contracts) return null;

    var reasons = [], total = 0;
    var fi = T.indexOf('유찰 사유');
    if (fi >= 0) {
      var seg = T.slice(fi, fi + 1800).replace(/\s+/g, ' ');
      var tm = seg.match(/총\s*유찰\s*([\d,]+)\s*건/);
      if (tm) total = num(tm[1]);

      var cut = seg.indexOf('기준');
      var blk = cut >= 0 ? seg.slice(cut + 2) : seg.replace(/^유찰 사유\s*(분포)?/, '');

      var re = /(.+?)\s*([\d,]+)\s*건\s*[·.]\s*[\d.]+\s*%/g, m;
      while ((m = re.exec(blk)) !== null) {
        var label = m[1].trim().replace(/^[·\-,\s]+/, '');
        if (!label || /^총/.test(label) || label.length > 60) continue;
        reasons.push({ label: label, count: num(m[2]) });
        if (reasons.length >= 12) break;
      }
    }
    if (!total) total = reasons.reduce(function (s, r) { return s + r.count; }, 0);

    var pm = T.match(/(\d{2}\.\d{2}\.\d{2})[^\d]*[~\-–][^\d]*(\d{2}\.\d{2}\.\d{2})/);

    return {
      period: pm ? (pm[1] + ' ~ ' + pm[2]) : '',
      kpi: kpi,
      failed: { total: total, reasons: reasons },
      savedBy: '씨마켓 자동동기화'
    };
  }

  function send(body) {
    var sig = JSON.stringify(body.kpi) + '|' + body.failed.total
            + '|' + body.failed.reasons.length;
    var prev = null;
    try { prev = localStorage.getItem(SIG_LS); } catch (e) {}
    if (prev === sig) { badge('#94a3b8', '최신 상태 · 마감 ' + body.kpi.closed); return; }

    var key = null;
    try { key = localStorage.getItem(KEY_LS); } catch (e) {}
    if (!key) {
      key = prompt('업무포털 수정 키(BID_EDIT_KEY)를 한 번만 입력해 주세요');
      if (!key) { badge('#dc2626', '수정 키 없음'); return; }
      try { localStorage.setItem(KEY_LS, key); } catch (e) {}
    }

    busy = true;
    badge('#f59e0b', '전송 중…');

    fetch(PORTAL + '/api/bid', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', 'X-Edit-Key': key },
      body: JSON.stringify(body)
    })
      .then(function (r) { return r.json().then(function (j) { return { s: r.status, j: j }; }); })
      .then(function (res) {
        busy = false;
        if (res.j && res.j.success) {
          try { localStorage.setItem(SIG_LS, sig); } catch (e) {}
          badge('#16a34a', '전송 완료 · 마감 ' + body.kpi.closed);
          toast('포털 갱신됨 · 진행중 ' + body.kpi.inProgress + ' / 마감 ' + body.kpi.closed);
        } else {
          badge('#dc2626', '실패 ' + res.s);
          toast('포털 전송 실패: ' + ((res.j && res.j.message) || res.s), true);
          if (res.s === 401) { try { localStorage.removeItem(KEY_LS); } catch (e) {} }
        }
      })
      .catch(function (e) {
        busy = false;
        badge('#dc2626', '네트워크 오류');
        toast('포털 전송 실패: ' + e.message, true);
      });
  }

  function tick() {
    if (busy) return;
    var body = read();
    if (body) send(body);
    else badge('#cbd5e1', '요약 화면 대기 중');
  }

  badge('#cbd5e1', '시작됨');
  setTimeout(tick, 3000);
  setInterval(tick, 15000);

  var lastUrl = location.href;
  setInterval(function () {
    if (location.href !== lastUrl) { lastUrl = location.href; setTimeout(tick, 2500); }
  }, 1500);

  // 10분마다 화면을 새로 받아옵니다 — 그 탭을 보고 있지 않을 때만
  setInterval(function () {
    if (document.hidden && document.body.innerText.indexOf('나의 거래 요약') >= 0) {
      location.reload();
    }
  }, 600000);
})();
```

## 확인 방법 — 콘솔 열 필요 없습니다

씨마켓 화면 **오른쪽 아래 구석**에 작은 점이 하나 생깁니다. 마우스를 올리면 상태가 뜹니다.

| 점 색 | 뜻 |
|---|---|
| 연회색 | 요약 화면 대기 중 (다른 화면에 있음) |
| 주황 | 전송 중 |
| **초록** | **전송 완료** (오른쪽 아래 초록 알림도 뜸) |
| 회색 | 이미 최신 — 보낼 값이 없음 |
| 빨강 | 실패 |

> 점이 **씨마켓 채팅 위젯(파란 동그라미)에 가려 잘 안 보입니다.**
> 잘 보이게 하려면 `badge` 함수의 `right:10px;bottom:10px;width:11px;height:11px;border-radius:50%`
> 부분을 `left:12px;bottom:12px;padding:6px 12px;border-radius:999px` 로 바꾸고
> `dot.style.background` 다음 줄에 `dot.textContent = '포털 ' + tip;` 을 넣으면
> 왼쪽 아래에 글자가 있는 띠로 나옵니다.

**점이 아예 안 보이면** → 스크립트가 그 페이지에 안 붙은 것입니다. 맨 위 「사용자 스크립트 허용」 확인.

**강제로 다시 보내기** (같은 값이라 건너뛸 때):
```javascript
localStorage.removeItem('fiti.bidSig'); location.reload();
```

## 수정 키

포털 Vercel 프로젝트(`fiti-procurement-portal`)의 환경변수 **`BID_EDIT_KEY`**.
이 값이 없으면 포털은 **읽기 전용**으로만 동작합니다(아무나 숫자를 바꾸지 못하게).
값을 바꿨으면 **Redeploy** 해야 반영됩니다. Secret 타입은 값을 다시 볼 수 없으니, 모르면 덮어쓰세요.

스크립트는 처음 한 번만 물어보고 그 브라우저의 `localStorage['fiti.bidKey']` 에 기억합니다.
401 이 오면 저장된 키를 지우고 다음 번에 다시 물어봅니다.

## 더 튼튼하게 하려면

지금은 **화면 글자**를 읽습니다. 씨마켓이 문구를 바꾸면 깨질 수 있습니다.
씨마켓 Partner API 가 나오면 `00.업무포털/api/bid.js` 의 **데이터 출처만 교체**하면 되고,
이 유저스크립트는 통째로 버리면 됩니다.

그 전에 임시로 더 안정화하려면 `F12 → Network → Fetch/XHR` 에서 그 숫자가 담긴
**JSON 요청 주소**를 찾아 알려주세요. 글자 대신 그 API 를 직접 읽도록 바꿀 수 있습니다.
