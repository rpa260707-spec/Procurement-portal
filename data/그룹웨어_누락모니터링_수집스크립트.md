# 입찰 누락 모니터링 — 그룹웨어 수집 스크립트

> 포털 「입찰구매 현황」 카드 아래 **누락 모니터링** 위젯에 들어갈 데이터를 만듭니다.

그룹웨어(`gw.fiti.re.kr`)는 로그인 쿠키가 있어야 읽히므로 **포털 서버가 직접 못 부릅니다.**
이미 로그인해 있는 **내 브라우저**가 목록을 읽어 포털로 보내는 구조입니다 — 씨마켓과 같은 방식입니다.

아이디·비밀번호는 어디에도 저장되지 않습니다.

---

## 무엇을 잡아내나

| 탭 | 뜻 | 판정 |
|---|---|---|
| **입찰 누락** | 품의만 올리고 입찰을 안 보냄 | 입찰 전송일시가 **비어 있음** |
| **마감 후 정체** | 마감일이 지났는데 아직 진행중 | 입찰 마감일시 **< 오늘** + 상태가 진행중 |
| **유찰** | 유찰인데 재공고도 취소도 안 함 | 진행단계 **유찰** + 다음 단계로 안 넘어감 |

각 건의 **경과일**을 같이 계산합니다. 포털에서 **10일 이상 적색 · 7일 이상 주황**으로 표시됩니다.

> **경과 14일이 넘은 건은 담지 않습니다 — 단 「유찰」은 예외로 전부 담습니다.**
> 그만큼 묵은 건은 따로 사유가 있어 손대지 않는 것이라, 목록에 남겨 두면 진짜 챙겨야 할 건이 묻힙니다.
> 수집 스크립트와 포털 API **양쪽에서** 거릅니다.

---

## 쓰는 법

> **Amaranth10 목록은 `<table>` 이 아니라 그리드라서 화면 글자를 직접 못 읽습니다** (2026-10-20 확인 —
> 「입찰 목록 표를 찾지 못했습니다」가 그 증상). 그래서 그리드 자체 기능 **「클립보드로 복사」** 로 받습니다.

1. 그룹웨어 **입찰정보관리(CDTS5122)** 를 열고 조회합니다
   (구매업무는 **전체**로 두어도 됩니다 — 스크립트가 **입찰-소모품만** 골라냅니다)
2. 목록 위에서 **마우스 오른쪽 → 클립보드로 복사**
3. 즐겨찾기 **[누락 모니터링 수집]** 클릭
4. 「붙여넣기」 상자가 뜨면 `Ctrl+V` → **읽기**
   (크롬이 「클립보드 보기 허용」을 물으면 **허용** — 그러면 상자 없이 바로 읽습니다)
5. 확인창의 숫자를 보고 **확인** → 포털에 저장

처음 한 번은 **수정 키**를 물어봅니다. 포털 Vercel 환경변수 `BID_EDIT_KEY` 값이며,
씨마켓 동기화와 **같은 키**입니다. 한 번 넣으면 그 브라우저가 기억합니다.

> 확인창의 **「읽은 줄」** 이 그리드 아래 총 건수와 비슷한지 보세요. 크게 적으면 복사가 일부만 된 것입니다.

## 코드

```javascript
(function () {
  var PORTAL = 'https://fiti-procurement-portal.vercel.app';
  var KEY_LS = 'fiti.bidKey';
  var MAX_DAYS = 14;   // 경과 14일이 넘은 건은 뺍니다 — 따로 사유가 있는 건이라 보고 제외합니다

  // ── 머리글 이름으로 칸 위치를 잡습니다 (열 순서가 바뀌어도 따라갑니다)
  var WANT = {
    prNo:  ['구매번호', '구매 번호', '요청번호'],
    bidNo: ['입찰번호', '입찰 번호'],
    item:  ['공고명', '품명', '품목명', '건명', '구매명', '요청명', '대표품목'],
    step:  ['진행단계', '진행 단계'],
    dept:  ['수요 부서', '수요부서', '요청부서', '신청부서'],
    emp:   ['수요 사원', '수요사원', '담당자', '신청자', '요청자', '기안자'],
    work:  ['구매업무'],
    sendDt:['입찰 전송일시', '입찰전송일시', '전송일시'],
    endDt: ['입찰 마감일시', '입찰마감일시', '마감일시'],
    state: ['입찰 상태', '입찰상태']
  };
  /* 복사본에 머리글 줄이 없을 때 쓰는 CDTS5122 화면 순서 (구매번호부터) */
  var ORDER = ['prNo', 'bidNo', 'item', 'step', 'dept', 'emp', 'work', 'sendDt', 'endDt', 'state'];
  var PRNO_RE = /^C[A-Z]\d{10,}$/;   // CS2026102000018 · CP… · CB…

  function clean(v) { return String(v == null ? '' : v).replace(/\s+/g, ' ').trim(); }

  function colMap(heads) {
    var m = {};
    Object.keys(WANT).forEach(function (k) {
      m[k] = -1;
      heads.forEach(function (h, i) {
        if (m[k] < 0 && WANT[k].some(function (w) { return h.indexOf(w) >= 0; })) m[k] = i;
      });
    });
    return m;
  }

  /* 클립보드 글(탭으로 칸, 줄바꿈으로 줄)을 머리글 + 줄 배열로 */
  function fromText(text) {
    var lines = String(text || '').replace(/\r/g, '').split('\n')
      .filter(function (l) { return l.replace(/\t/g, '').trim(); })
      .map(function (l) { return l.split('\t').map(clean); });
    if (!lines.length) return null;
    var hi = -1;
    for (var i = 0; i < Math.min(lines.length, 5); i++) {
      if (lines[i].some(function (c) { return c.indexOf('구매번호') >= 0; })) { hi = i; break; }
    }
    if (hi >= 0) {
      var heads = lines[hi];
      return { col: colMap(heads), heads: heads, rows: lines.slice(hi + 1) };
    }
    /* 머리글이 없으면 구매번호처럼 생긴 칸을 기준으로 화면 순서를 댑니다 */
    var probe = lines.filter(function (r) { return r.some(function (c) { return PRNO_RE.test(c); }); })[0];
    if (!probe) return null;
    var base = probe.findIndex(function (c) { return PRNO_RE.test(c); });
    var col = {};
    Object.keys(WANT).forEach(function (k) { col[k] = -1; });
    ORDER.forEach(function (k, j) { col[k] = base + j; });
    return { col: col, heads: ['(머리글 없음 — 화면 순서로 읽음)'], rows: lines };
  }

  /* 혹시 일반 <table> 화면이면 그대로 읽습니다 (iframe 안까지) */
  function fromDom() {
    var docs = [];
    (function walk(w) {
      try { if (w.document) docs.push(w.document); } catch (e) { return; }
      for (var i = 0; i < w.frames.length; i++) walk(w.frames[i]);
    })(window.top);
    var best = null, bestHit = 0;
    docs.forEach(function (d) {
      Array.prototype.forEach.call(d.querySelectorAll('table'), function (tb) {
        var hs = Array.prototype.map.call(tb.querySelectorAll('th'), function (e) { return clean(e.textContent); });
        var col = colMap(hs);
        var hit = Object.keys(col).filter(function (k) { return col[k] >= 0; }).length;
        if (hit > bestHit) { bestHit = hit; best = { tb: tb, heads: hs, col: col }; }
      });
    });
    if (!best || bestHit < 4) return null;
    var rows = Array.prototype.map.call(best.tb.querySelectorAll('tbody tr'), function (tr) {
      return Array.prototype.map.call(tr.children, function (td) {
        var s = clean(td.textContent), t = clean(td.getAttribute('title'));
        return (t && /(?:…|\.\.\.)$/.test(s)) ? t : s;
      });
    });
    return { col: best.col, heads: best.heads, rows: rows };
  }

  /* 클립보드 바로 읽기가 막히면 붙여넣기 상자를 띄웁니다 */
  function askPaste(done) {
    var box = document.createElement('div');
    box.style.cssText = 'position:fixed;inset:0;z-index:2147483647;background:rgba(0,0,0,.45);display:flex;align-items:center;justify-content:center;font:14px sans-serif';
    box.innerHTML = '<div style="background:#fff;padding:18px;border-radius:10px;width:min(560px,92vw)">'
      + '<b>누락 모니터링 수집</b><p style="margin:8px 0">그리드에서 <b>오른쪽 클릭 → 클립보드로 복사</b> 한 뒤, 아래 칸에 <b>Ctrl+V</b></p>'
      + '<textarea style="width:100%;height:160px;box-sizing:border-box"></textarea>'
      + '<div style="text-align:right;margin-top:8px"><button data-x>취소</button> <button data-ok style="font-weight:bold">읽기</button></div></div>';
    document.body.appendChild(box);
    var ta = box.querySelector('textarea');
    ta.focus();
    box.querySelector('[data-x]').onclick = function () { box.remove(); };
    box.querySelector('[data-ok]').onclick = function () { var v = ta.value; box.remove(); done(v); };
  }

  function toDate(v) {
    var m = String(v || '').match(/(\d{4})[.\-\/]?(\d{2})[.\-\/]?(\d{2})/);
    if (!m) return null;
    var d = new Date(+m[1], +m[2] - 1, +m[3]);
    return isNaN(d) ? null : d;
  }
  function daysAgo(d) {
    if (!d) return 0;
    var t = new Date(); t.setHours(0, 0, 0, 0);
    return Math.max(0, Math.round((t - d) / 86400000));
  }
  /* 구매번호에 날짜가 들어 있습니다 — CS2026060200009 → 2026-06-02.
     마감일 칸이 비어 있을 때 경과일을 이것으로 셉니다. */
  function prNoDate(s) {
    var m = String(s || '').match(/(\d{4})(\d{2})(\d{2})/);
    if (!m) return null;
    var d = new Date(+m[1], +m[2] - 1, +m[3]);
    return isNaN(d) ? null : d;
  }

  function run(g) {
    if (!g) {
      alert('목록을 읽지 못했습니다.\n\n그리드에서 오른쪽 클릭 → 「클립보드로 복사」 를 먼저 하고 다시 눌러 주세요.');
      return;
    }
    var col = g.col;
    var out = { notSent: [], stalled: [], failed: [] }, total = 0, other = 0;
    var idx = {};
    var today = new Date(); today.setHours(0, 0, 0, 0);

    g.rows.forEach(function (c) {
      function at(k) { return col[k] >= 0 && c[col[k]] != null ? c[col[k]] : ''; }
      var prNo = at('prNo');
      if (!PRNO_RE.test(prNo)) return;                // 머리글·소계·빈 줄 건너뜀
      var work = at('work');
      if (col.work >= 0 && work && !/소모품/.test(work)) { other++; return; }   // 입찰-소모품만
      total++;

      var rec = { prNo: prNo, item: at('item'), dept: at('dept'), emp: at('emp'), endDt: at('endDt'), step: at('step') };
      var seen = idx[prNo] || (idx[prNo] = { item: '', dept: '', emp: '' });
      if (!seen.item && rec.item) seen.item = rec.item;
      if (!seen.dept && rec.dept) seen.dept = rec.dept;
      if (!seen.emp  && rec.emp)  seen.emp  = rec.emp;

      var send = toDate(at('sendDt'));
      var end  = toDate(at('endDt'));
      var step = rec.step;
      var state = at('state');
      var live = /진행/.test(step) || /진행/.test(state);
      var base = end || prNoDate(prNo);
      rec.days = daysAgo(base);

      /* ① 유찰을 가장 먼저 — 유찰 건은 전송일시가 비어 있기도 해서 「입찰 누락」으로 잘못 들어갑니다 */
      if (/유찰/.test(step) && !/구매계약|발주|재공고|취소/.test(state)) { out.failed.push(rec); return; }
      /* ② 입찰 누락 — 전송일시가 없음 */
      if (!send) { if (base && rec.days <= MAX_DAYS) out.notSent.push(rec); return; }
      /* ③ 마감 후 정체 — 마감일이 지났는데 진행중 */
      if (end && end < today && live && rec.days <= MAX_DAYS) out.stalled.push(rec);
    });

    ['notSent', 'stalled', 'failed'].forEach(function (k) {
      out[k].forEach(function (r) {
        var s = idx[r.prNo];
        if (!s) return;
        if (!r.item) r.item = s.item;
        if (!r.dept) r.dept = s.dept;
        if (!r.emp)  r.emp  = s.emp;
      });
    });

    var all = out.notSent.concat(out.stalled, out.failed);
    console.log('[누락모니터링] 머리글', g.heads);
    console.log('[누락모니터링] 칸 위치', col);
    if (console.table) console.table(all);

    if (!total) {
      alert('입찰-소모품 줄을 하나도 못 찾았습니다.\n\n읽은 전체 줄 ' + g.rows.length + '줄 · 다른 구매업무 ' + other + '건\n'
        + 'F12 → Console 의 [누락모니터링] 줄을 캡처해 전략구매팀에 알려 주세요.');
      return;
    }

    var miss = [];
    if (col.item < 0) miss.push('공고명');
    if (col.dept < 0) miss.push('수요부서');
    if (col.emp  < 0) miss.push('수요사원');
    if (col.sendDt < 0) miss.push('입찰 전송일시');

    var msg = '포털에 보낼 값\n\n'
      + '입찰-소모품 ' + total + '건 읽음' + (other ? ' (다른 구매업무 ' + other + '건 제외)' : '') + '\n\n'
      + '입찰 누락      ' + out.notSent.length + '건\n'
      + '마감 후 정체   ' + out.stalled.length + '건\n'
      + '유찰           ' + out.failed.length + '건\n';
    if (miss.length) msg += '\n※ 못 찾은 칸 : ' + miss.join(' · ') + '\n   숫자가 이상하면 취소하고 Console 을 캡처해 주세요.\n';
    msg += '\n보낼까요?';
    if (!confirm(msg)) { console.log('[누락모니터링] 취소됨', out); return; }

    var key = null;
    try { key = localStorage.getItem(KEY_LS); } catch (e) {}
    if (!key) {
      key = prompt('포털 수정 키(BID_EDIT_KEY)');
      if (!key) return;
      try { localStorage.setItem(KEY_LS, key); } catch (e) {}
    }

    fetch(PORTAL + '/api/bid-monitor', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', 'X-Edit-Key': key },
      body: JSON.stringify({
        scope: '입찰-소모품', totalRows: total, savedBy: '그룹웨어 수집',
        notSent: out.notSent, stalled: out.stalled, failed: out.failed
      })
    })
      .then(function (r) {
        return r.text().then(function (t) {
          try { return JSON.parse(t); }
          catch (e) { return { success: false, message: 'HTTP ' + r.status + ' — ' + t.slice(0, 120) }; }
        });
      })
      .then(function (j) {
        alert(j.success
          ? ('포털에 저장했습니다.\n\n입찰 누락 ' + j.counts.notSent + ' / 마감 후 정체 ' + j.counts.stalled + ' / 유찰 ' + j.counts.failed)
          : ('실패: ' + (j.message || '')));
        if (!j.success && /키/.test(j.message || '')) { try { localStorage.removeItem(KEY_LS); } catch (e) {} }
      })
      .catch(function (e) {
        alert('전송 실패: ' + e.message + '\n\n그룹웨어가 바깥(vercel.app)으로 보내는 것을 막았을 수 있습니다.\nF12 → Console 의 빨간 줄을 캡처해 주세요.');
      });
  }

  var dom = fromDom();
  if (dom) { run(dom); return; }
  var viaBox = function () { askPaste(function (t) { run(fromText(t)); }); };
  if (navigator.clipboard && navigator.clipboard.readText) {
    navigator.clipboard.readText()
      .then(function (t) { var g = fromText(t); if (g) run(g); else viaBox(); })
      .catch(viaBox);
  } else {
    viaBox();
  }
})();
```

## 잘 안 될 때

| 보이는 것 | 원인 | 조치 |
|---|---|---|
| 「붙여넣기」 상자가 계속 뜸 | 크롬이 클립보드 읽기를 막음 | 상자에 `Ctrl+V` 하면 똑같이 됩니다 |
| 「목록을 읽지 못했습니다」 | 클립보드가 비었거나 다른 글이 들어 있음 | 그리드 **오른쪽 클릭 → 클립보드로 복사** 후 다시 |
| 「입찰-소모품 줄을 하나도 못 찾았습니다」 | 머리글 이름이 바뀜 | Console 캡처를 주시면 `WANT` 에 추가합니다 |
| 「수정 키가 맞지 않습니다」 | 키 오타 | 다시 실행하면 새로 물어봅니다 |
| 「수정 키가 설정되지 않아…」 | Vercel 에 `BID_EDIT_KEY` 없음 | 환경변수 넣고 **Redeploy** |
| 전송 실패 (Failed to fetch) | 회사 네트워크·그룹웨어가 vercel.app 차단 | Console 캡처 |

## 저장되는 것

개인정보는 담지 않습니다. **담당자는 이름만** 받고 사번·연락처·금액은 저장하지 않습니다.
탭당 **300건**까지 자릅니다.

저장소는 씨마켓과 같은 Vercel Blob 이고 파일명만 다릅니다 (`portal-bid-monitor.json`).
**배포 없이 갱신**되므로, 이 스크립트만 돌리면 포털이 바로 최신이 됩니다.

## 한 번 누르면 되는 북마클릿

### 만드는 법

1. 브라우저 즐겨찾기 막대에서 **마우스 오른쪽 → 페이지 추가** (이미 만들었으면 그 즐겨찾기 **오른쪽 클릭 → 수정**)
2. **이름** `누락 모니터링 수집`
3. **URL** 칸에 아래 블록을 **통째로** 붙여넣기 (한 줄입니다)
4. 저장

> 코드를 고치면 **이 북마클릿도 다시 만들어야** 합니다. 위 코드와 아래 한 줄은 같은 내용이어야 합니다.
> 아래 줄은 위 코드에서 자동으로 만듭니다(주석 줄 제거 · 퍼센트 인코딩).
