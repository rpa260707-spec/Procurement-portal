# 08. 수요부서

수요부서가 쓰는 화면입니다. **두 겹**입니다.

| 파일 | 무엇 | 로그인 |
|---|---|---|
| `index.html` | 수요부서 업무포털 — 지침 · 단가 · 구매 이력 · 구매요청 바로가기 | **없음** |
| `supplies.html` | 소모품 구매 이력 — 언제 · 수의/입찰 · 어느 업체. **단가 없음** | **없음** |
| `dept.html` | 수요부서 구매현황 — 우리 부서 발주 내역 · 검수 대기 | **GRFITI 계정** |
| `data/supplies.json` | 위 화면의 자료. 구매 이력에서 **단가 · 금액을 뺀 것** (4,025종) | |
| `api/market.js` | 환율. **구매팀 포털을 부르지 않으려고** 이 프로젝트가 직접 받아옵니다 | |
| `api/auth.js` | 로그인 · 연장 · 로그아웃 대행 (키가 화면 소스에 안 나감) | |
| `api/dept.js` | 토큰으로 부서 확인 후 **그 부서 건만** 돌려줌 | |
| `api/_supabase.js` | Supabase 주소 · `ADMIN_DEPTS` | |
| `vercel.json` | 검색엔진 수집 차단 · Referrer 차단 | |

**구매팀 포털(`fiti-procurement-portal`)을 부르는 곳이 한 군데도 없습니다.** 환율도 이 프로젝트 함수가 직접 받습니다.
첫 화면(`index.html`)은 **링크 모음**이라 키 없이도 바로 뜹니다.
`dept.html` 만 `SUPABASE_ANON_KEY` 와 Blob 연결이 필요합니다.

### 현황 줄 (머리말 아래)
**환율 세 가지만** 보여 줍니다 — 원/달러 · 원/100엔 · 원/유로. 수입 시약 · 기자재 단가를 가늠할 때 씁니다.
포털 중계 API `…/api/market` 에서 받습니다. **이 화면에는 토큰도 키도 없습니다.**
유가 · 금속 · 입찰 현황 · 누락 모니터링 · 발주 금액은 넣지 않았습니다. 못 받으면 줄째로 숨깁니다.

### 소모품 검색 미리보기
가격검색 카드의 검색창에 **두 글자**부터 치면 바로 아래에 실구매 이력 5건이 뜹니다
(`price-sand.vercel.app/api/search?q=`). 누르면 가격검색에서 열립니다.

### 지침 탭 (지침 칸 아래)
**입찰 · 수의계약 · 낙찰 방식 · 비거주 지침** 네 탭. 각 탭 아래에 근거 규정을 **풀네임과 최종개정일**까지 적었습니다.

| 탭 | 근거 |
|---|---|
| 입찰 · 수의계약 · 낙찰 방식 | **4-1-4 「구매 및 계약 업무요령」** 최종개정 2025.04.30. (단가계약 제15조의2) |
| 금액 기준 | **구매 가이드북 제1장 「물품구매 계약업무」** 2026.08.01. 개정 — 원문 PDF 로 보냅니다 |
| 비거주 지침 | **인사관리 3-2-2 「비거주지 근무직원에 대한 지원금 운영요령」** 최종개정 2025.07.01. |

**금액 기준은 싣지 않습니다.** PDF 에서 숫자가 글자와 떨어져 나와 정확히 뽑지 못했습니다. 틀린 금액을 띄우느니 원문을 보게 했습니다.

### 바깥 시스템은 새 탭으로
소모품 가격검색 · 재고관리 · 업무매뉴얼 링크는 **모두 새 탭**으로 엽니다.
같은 탭으로 넘기면 그 앱의 「← 업무포털」 버튼이 **전략구매팀 포털**로 데려갑니다.
`dept.html` 만 같은 탭입니다.
### 구매요청 바로가기 (그룹웨어)
소모품 구매요청 `CDTS5108` · 입찰 구매요청 `CDTS5121` · 전자결재 대기함 `UCA2010`

**소모품 가격검색은 공유합니다.** 요청 금액을 적기 전에 봐야 하는 자료라 비밀번호를 걸지 않습니다.

## 배포

1. Vercel 새 프로젝트로 이 폴더를 올립니다 → 포털은 바로 뜹니다
2. `SUPABASE_ANON_KEY` 환경변수 (**service_role 키 넣지 말 것**)
3. Storage → Blob **Connect Store → Redeploy** (구매 데이터는 01 구매현황과 같은 저장소 `procurement-state.json`)
4. 실제 GRFITI 계정으로 `dept.html` 로그인 확인 — 부서가 제대로 잘리는지
